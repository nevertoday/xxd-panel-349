## 适用场景与解决的问题

适合有一个清楚主体、脚下带着一小块地方的照片：海边的房子、田里的谷仓、路边的车、水上的船、山间的桥、一棵独树。也适合构图差、背景乱、主体小的照片——下半会删掉环境，只把主体和脚下一块切成方块堆成的小岛，让边缘散成碎方块，把它救成一张成立的速写本小水彩。照片本身是街道、风景或室内时，只取最有代表性的一个单体或片段。

关键是主体身上不留一处照片质感，全部是几大块圆角长方形的单色平涂，横着摞起、稍稍错开叠压；上半是照片里最鲜明的颜色，底座是最深的颜色，中间夹几块中间色；边缘不画轮廓而是断成越往外越小越稀的碎方块；深色块里留出往下淌、偶尔拐直角的白线；色块边缘一道略深的水痕；整组像小岛一样浮在大片白底中间、不碰任何一边；右下方一行字距拉开的手写小字。避免完整场景复刻、背景填满、主体保留照片样子只把脚下变方块、整齐的像素格、轮廓线、碎方块撒满画面、写实水彩晕染、画出地平线和天空、颜色太多太杂，以及把白线画成随意的高光。

## 使用窍门

- **先给一张清楚的照片：** 先选一张主体、动作和关系都容易辨认的图，再决定输出方式与比例。
- **一句话串起参数：** 直接说“上下对照 / 左右对照 / 纯设计 + 16:9 / 3:4 / 手机壁纸”，也可以补充电脑、平板或电子手表尺寸。
- **把必须保留的内容说清楚：** 指定人物、物件、动作、关系和文字；避免同时规定过多布局细节，让风格有空间完成设计。
- **文字有三种选择：** 让模型按图片智能生成、用 `--text exact --copy` 锁定逐字文案，或用 `--text none` 完全不要文字。
- **说明现实区与设计区：** 上下或左右对照时，注明哪一侧保留照片、哪一侧负责设计转译；纯设计和壁纸则说明整张画布都要重新设计。
- **先单张试，再批量做：** 先用一张图确认模式、比例、文字和语言，再把同一套参数用于目录批处理；每轮只改一个变量，结果更容易比较。

## 开始使用

从 GitHub 安装：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-349 --skill xxd-panel-349
```

安装后重新启动 Agent 会话，然后调用 `$xxd-panel-349`。也可以按需追加 `--global --agent codex --yes` 做用户级安装。

常用调用示例：

```text
/xxd-panel-349 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-349 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-349 photo.jpg --mode design-only --size 9:16 --text none --prefs off
/xxd-panel-349 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

完整运行契约见 [SKILL.md](SKILL.md)；运行适配器见 [英文](references/xxd-panel-349-prompt.en.md) 与 [中文](references/xxd-panel-349-prompt.zh-CN.md)。

## 快速判断：Panel 349 适合你吗？

既要保留源图身份，也要重新构图；既要材质特征，也要主动留白。可选准确文字、智能文案或无文字；支持单图、递归目录批量以及下方四种交付模式。

## 四种输出模式

- `top-bottom`：整张画布只有上下两个全宽区域，现实照片在上、设计在下，严格各占 50%。
- `left-right`：整张画布只有左右两个全高区域，现实照片在左、设计在右，严格各占 50%，不会旋转成上下结构。
- `design-only`：整张画布只呈现 Panel 349 的设计转译，照片只作为不可见参考。
- `wallpaper-pack`：按手机、iPad、桌面和手表分别生成完整设计壁纸，可选 `linked` 连贯套装或 `independent` 四张独立。

支持多选模式与比例（`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5` 或准确像素），以及模型生成文字、准确文字和无文字。传入目录会递归扫描图片，每张源图独立处理，共用一次交付设置；最终 PNG 平铺放入一个新任务目录。
